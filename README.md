# askme.mcp

One place where all of a person's AI agents ask for their input, sorted by rules the person writes in plain English.

**Status:** being built, one issue at a time. Every green merge to main deploys the live site, and the summary of the latest [deploy run](https://github.com/t-d-d/askme-mcp/actions/workflows/deploy.yml) gives its address.

- [PRD.md](PRD.md): what version 1 does, what it leaves out, and the roadmap.
- [docs/adr/](docs/adr/README.md): the technical decisions, one record each.
- [docs/constraints/](docs/constraints/README.md): the rules those decisions put in force.
- [docs/design.md](docs/design.md): how it looks, behaves and speaks, with pictures of every screen.
- [CLAUDE.md](CLAUDE.md) and [.claude/](.claude/): how the agents that write the code are told to work.
